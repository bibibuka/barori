# План: правки формы заявки (ContactForm.tsx)

## Контекст
Форма в `src/components/ContactForm.tsx` имеет переключатель «Кто вы?»:
- `applicant` = «Хочу устроиться» → свободный текст «Желаемая должность» + «Сообщение».
- `employee` = «Я уже работаю» → dropdown «Отдел» (Доставка, Кухня, Зал/Касса, **Бухгалтерия**, **Администрация**, Другое) + «Опишите проблему».

Нужно перераспределить варианты между двумя состояниями, добавить поле «Город» и убрать авто-подстановку должности из карточки вакансии.

## Решения (согласовано с пользователем)
- Поле «Город» — **свободный ввод** (текст), обязательно к заполнению.
- Отклик из карточки вакансии — **убрать** (больше не подставлять должность в форму; баннер «Вы откликаетесь на: X» убрать). Кнопка «Откликнуться на вакансию» в модалке остаётся как простой переход к форме (без подстановки).
- Список должностей (applicant) — **«ваши + базовые»**.
- Блок «Я уже работаю» — переименовать «Отдел» → **«Сервис»**, оставить «Другое».

## Замечание по бэкенду
Бэкенд-обработчик `/local/tools/form-handler.php` (Bitrix) в репозитории отсутствует. Новый параметр `city` будет отправляться клиентом; нужно убедиться, что серверный обработчик/письмо принимает и сохраняет поле `city` (обычно достаточно, т.к. значения читаются из FormData). Имена ключей (`department`, `position`, `message`, `problem`) намеренно сохранены для совместимости.
