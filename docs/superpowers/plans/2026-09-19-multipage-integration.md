# Объединение страниц

Цель: связать семь существующих страниц общей навигацией, сохранив адреса, наполнение и оформление направлений. Использовать существующую многостраничную сборку Vite, обычные ссылки и нативные элементы браузера без новых зависимостей.

- [x] Снять текстовый снимок страниц и проверить исходные тесты.
- [x] Добавить общую навигацию в оба каркаса, ссылки на главную и обозначение текущей страницы. Сохранить навигацию внутри страниц.
- [x] Исправить подтверждение отправки формы, проверить ошибки без отправки реальных заявок.
- [x] Исправить клавиатурное управление окнами, мобильные отступы, safe area, фокус и уменьшение движения.
- [x] Проверить все страницы в Chromium и WebKit при ширинах 320–1440 px, переходы, формы, окна, отсутствие горизонтального переполнения и сохранность текста.
- [x] Выполнить тесты, TypeScript и сборку. Открыть работающий localhost.

Ограничения проверки: WebKit на Windows не заменяет физический Mac/iPhone. PHP обработчик зависит от Bitrix; локальные проверки форм используют подмену ответа сервера и капчи, без реальных заявок.

Результат: 41 тест пройден, TypeScript без ошибок, production-сборка успешна. 98 проверок страниц (7 адресов × 7 размеров × 2 движка), 28 сценариев взаимодействия (7 адресов × 2 размера × 2 движка), отдельная проверка калькуляторов и FAQ пройдены. Адрес /tariffs/ подключён к уже существующему TariffsLanding вместо ошибочной копии главной. Три исходные ссылки-заглушки в базе знаний отмечены недоступными без изменения названий.
